# Codex Remote macOS 图标设计

日期：2026-08-06
状态：已实施并验证

## 1. 目标

为 Codex Remote 生成并接入一套 macOS 图标：

- App 图标用于 Dock、Finder、启动台和应用包。
- 菜单栏图标覆盖现有三类蓝牙连接状态。
- 两类图标共享“终端提示符 + 无线连接”核心符号。

本次不修改 BLE、会话状态或跨端协议，不把执行中、完成未读、等待输入、错误等会话状态聚合到菜单栏图标。

## 2. 视觉方向

采用 A1“原生科技蓝”方案。

App 图标使用 macOS 圆角方形轮廓。背景从亮蓝过渡到深蓝和深灰，保留适度高光与内阴影。主体使用白色 `>_` 终端提示符，右侧配置浅蓝无线波纹。图标不包含产品名称、字母缩写或其他文字。

设计重点：

- 终端提示符表达 Codex CLI 会话。
- 无线波纹表达 Mac 与 ESP32 设备的 BLE 连接。
- 深色底和蓝色主调延续设备端界面及“执行中”状态的视觉基线。
- 主轮廓在 16 px 下仍可识别；小尺寸允许减少无线波纹细节。

## 3. App 图标资源

先生成 1024 × 1024 PNG 主图，再导出 macOS 标准图标尺寸并制作 `CodexRemote.icns`。

导出尺寸包括：

- 16 × 16、32 × 32
- 32 × 32、64 × 64 Retina
- 128 × 128、256 × 256
- 256 × 256、512 × 512 Retina
- 512 × 512、1024 × 1024 Retina

图标边缘保留安全留白。系统负责 App 图标蒙版，源图不得把主体贴到画布边缘。

## 4. 菜单栏三态图标

菜单栏使用单色模板效果，自动适配浅色、深色和高对比度模式。图标保留 `>_` 主轮廓，通过无线波纹和状态标记区分当前三类连接状态。

| 当前状态 | 视觉表达 | 现有状态映射 |
| --- | --- | --- |
| 已连接 | `>_` + 完整无线波纹 | `.ready` |
| 蓝牙不可用 | `>_` + 叹号 | 所有 `.unavailable(...)` |
| 未连接或连接中 | `>_` + 断开的无线波纹 | 其余 transport state |

菜单栏图标使用 SwiftUI 组合符号实现，不向 Swift Package 增加资源目录或依赖。菜单展开后的会话彩色圆点保持现状。

## 5. 工程接入

实施包含以下局部改动：

1. 在 `macos/App/` 保存 App 图标主图、iconset 和 ICNS 成品。
2. 在 `macos/App/Info.plist` 声明 Bundle 图标文件。
3. 在 `macos/Scripts/package-app.zsh` 把 ICNS 复制到应用包 `Contents/Resources/`，并将它加入打包完整性检查。
4. 在 `MenuBarStatusLabel` 中组合终端提示符和连接状态标记，继续复用 `AppModel.menuBarSymbol` 的现有三态分支或等价的明确映射。

实施不修改 Swift Package 根配置、公共 API、共享类型、BLE UUID、消息布局或 golden fixtures。

## 6. 验证

实施后执行以下验证：

1. 检查主图和所有导出尺寸，确认 PNG 尺寸、Alpha 通道及 ICNS 文件类型。
2. 以 16、32、64、128、256、512、1024 px 查看图标，确认主体居中、边缘清楚、无线波纹不过密。
3. 运行相关 Swift 定向测试，再运行完整 Swift 测试。
4. 执行发布打包脚本，确认应用包包含 `Contents/Resources/CodexRemote.icns`。
5. 使用 `plutil` 核对 `Info.plist`，使用 `codesign --verify` 核对打包后的应用签名。
6. 检查三种菜单栏连接状态的符号映射，确认浅色和深色模式下均可辨识。

## 7. 风险与边界

- AI 生成的 1024 px 主图可能在小尺寸出现细节粘连。实施阶段应检查每个导出尺寸，必要时只调整符号间距、留白或无线波纹数量。
- 菜单栏空间有限。状态符号应保持单色和紧凑，不复用 App 图标的渐变、阴影和高光。
- 本次只修改本地仓库。安装或替换 `/Applications/Codex Remote.app`、提交 Git 或推送远端均需另行确认。

## 8. 实施结果

- 已生成 SVG 主稿、1024 px PNG、10 个标准 iconset PNG 和 ICNS 成品。
- 已在 `Info.plist`、打包脚本和菜单栏 SwiftUI 标签中接入图标。
- 菜单栏继续使用现有三类连接状态，分别显示完整无线波纹、叹号和断开无线波纹。
- 7 个定向接线测试和 365 个 Swift 全量测试通过。
- 发布应用包通过 plist、ICNS、资源一致性和本机稳定签名验证。
